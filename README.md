# DecodeLabs Python Internship Projects

Welcome to my Python Internship repository powered by **DecodeLabs**. This repository contains production-ready Python applications developed during the internship, focusing on core programming concepts, state management, and defensive coding practices.

---

## 🛠️ Included Projects

### 1. To-Do List Application (`todo.py`)
A task management script that allows users to organize daily tasks effectively.
* **Key Features:** Add, view, and manage daily task entries via terminal interaction.
* **Core Logic:** Control structures, list data structures, and continuous user input loops.

### 2. Expense Tracker Application (`expense_tracker.py`)
A state-preserving financial tracking tool that handles continuous data entry and real-time computation.
* **Key Features:** 
  * Continuous expense logging using an accumulator pattern.
  * Defensive input validation to handle improper data types gracefully.
  * Clean output display showing individual entries and running total.
* **Core Logic:** While loops, `try-except` blocks, float casting, and accumulator state maintenance (`total += new_expense`).

### Running Project 2: Expense Tracker
